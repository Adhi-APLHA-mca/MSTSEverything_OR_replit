Open Rails

Free, open-source train simulator

C# / .NET MonoGame DirectX GPL Licensed MSTS Compatible Windows
Note: Open Rails is a Windows desktop application built with C#, MonoGame, and DirectX. It requires Windows + Visual Studio to build and run — it cannot execute in a Linux/web environment. This page serves as a project reference and setup guide.

About the Project

Open Rails is a community-developed, free and open-source train simulator designed to be compatible with Microsoft Train Simulator (MSTS) content. It supports the world's largest range of digital rail content including routes, rolling stock, activities, and timetables — all under the GPL license.

🚂

Simulation Engine

Multi-threaded architecture with dedicated Render, Updater, Loader, and Sound threads for maximum performance.

🔧

MSTS Compatible

Full backward compatibility with Microsoft Train Simulator routes, rolling stock, activities, and consists.

🌍

Open Source

Licensed under GPL. Community-designed and supported, ensuring continuous evolution and improvement.

📐

Modern Physics

Advanced physics including braking, steam/diesel/electric traction, superelevation, and more.

🌐

Multiplayer

Multiplayer server support for shared rail operations across a network.

🛠️

Included Tools

Track Viewer, Timetable Editor, Activity Editor, and Content Manager — all included in the solution.

Tech Stack

C# (.NET 4.7.2 / net6-windows) MonoGame (WindowsDX) DirectX via SharpDX OpenAL Soft (3D audio) Windows Forms / WPF MSBuild / NuGet Newtonsoft.Json Microsoft Roslyn (scripting) GNU.Gettext (i18n) XUnit (testing) Sphinx (documentation)

How to Build (Windows)

  1. Install Visual Studio 2019 or 2022 Select the .NET desktop development workload during installation.
  2. Clone the Repository Use git clone https://github.com/openrails/openrails.git or clone from within Visual Studio.
  3. Open the Solution Open Source/ORTS.sln in Visual Studio. Accept any framework install prompts.
  4. Rebuild Solution Use Build > Rebuild Solution. Compiled binaries are output to the Program/ folder.
  5. Add Content & Run Download content (e.g., Demo Model 1) from openrails.org. Run OpenRails.exe from the Program/ folder.
